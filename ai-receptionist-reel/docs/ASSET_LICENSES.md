# Asset and model notes

- All interface graphics and the medspa treatment illustration are original HTML/CSS created for this project.
- Ring, connection, notification, and ambient-bed audio were synthesized locally with FFmpeg for this project. They contain no sampled commercial recordings.
- Narration uses the Kokoro-82M `af_heart` voice through `kokoro-onnx` 0.6.1. The upstream wrapper is MIT licensed and its README identifies the Kokoro model as Apache-2.0. Recheck upstream terms before commercial deployment if the model or voice pack changes.
- HyperFrames is used through its pinned npm CLI version (`0.8.192`).
- GSAP 3.14.2 is vendored from the official npm package for deterministic offline rendering and is governed by GreenSock's package license terms.
- Manrope is vendored from `@fontsource-variable/manrope` 5.3.0 under the included OFL license.
- No stock photo, stock video, commercial song, paid speech service, or paid transcription API is included.
- The future real receptionist recording is private and intentionally excluded from Git.
