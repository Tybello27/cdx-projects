# AI Receptionist Reel — Editorial Signal System

## Style Prompt

A precisely art-directed vertical motion system combining premium SaaS interface design, editorial kinetic typography, and restrained 2.5D depth. Frames are built from flat color fields, hard crops, typographic masks, hairline rules, realistic UI states, and selective perspective. The work should feel authored in After Effects by a human designer: exact spacing, purposeful contrast, meaningful transitions, and no decorative CGI filler.

## Colors

- Warm ivory `#F5F0E9` — primary light canvas and text
- Forest green `#17251F` — primary dark canvas and typography
- Emerald `#008C69` — connected/active/AI state
- Burgundy `#782A3B` — missed-call warning only
- Mist `#D9DCD6` — customer waveform and neutral UI state

## Typography

- Display and body: `OpenAI Sans`, with 300/500/700 weight contrast
- Data and timing: `DejaVu Sans Mono`
- Display tracking: `-0.045em`; uppercase labels: `0.16em`

## Motion Language

- Primary transition: editorial push/track wipe, 0.32–0.45s, `power3.inOut`
- Accent transition: oversized type used as a mask, 0.45–0.55s, `expo.inOut`
- UI entries: 0.25–0.45s, confident `expo.out` / `power3.out`
- Camera: restrained 2.5D parallax or 3–6% push; never ambient zoom on every scene

## What NOT to Do

- No floating spheres, metallic ornaments, gold rings, marble sets, or generic AI imagery
- No glassmorphism, neon bloom, particle fields, or holographic interfaces
- No unconfirmed booking, reminder, calendar success, or automated comment-reply claim
- No inconsistent phone hardware or generated interface text
- No decorative element without a narrative or transition function
